# Voice Assistant

## Description

A Python voice assistant that listens to voice commands and performs basic tasks.

## Features

* Speaks to the user.
* Tells the current time and date.
* Opens Google and YouTube.
* Opens Calculator and Notepad.
* Recognizes voice commands.

## Technologies

* Python
* SpeechRecognition
* pyttsx3

## How to Run

Install the required libraries, connect a microphone, and run `python main.py`.
