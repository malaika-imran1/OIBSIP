# Weather App

## Description

A Python application that fetches weather information for a city using the OpenWeatherMap API.

## Features

* Accepts a city name from the user.
* Displays current weather information.
* Handles invalid city names and API errors.

## Technologies Used

* Python
* OpenWeatherMap API

## How to Run

1. Install Python.
2. Configure your OpenWeatherMap API key.
3. Run the application:

```bash
python main.py
```
